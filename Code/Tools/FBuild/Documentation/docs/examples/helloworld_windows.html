Hello World (Windows)

Overview

A minimal configuration for compiling a simple "Hello World" application on Windows.

The same program is shown built with two common Windows toolchains:

  • MSVC - the Microsoft Visual C++ toolchain.
  • MinGW-w64 - native GCC or Clang, which ship their own headers, import libraries and runtime.

Each example illustrates:

  • Declaring a Compiler()
  • Compiling a directory of cpp files with an ObjectList()
  • Linking the object files into an Executable()

The examples are deliberately explicit; real configurations usually factor shared settings into variables to reduce duplication.

Supported compilers on Windows

FASTBuild supports the following compilers on Windows: MSVC, Clang (including clang-cl) and GCC - including the GCC and Clang toolchains that come with MinGW-w64. The compiler family is normally detected automatically from the executable name, and can be set explicitly via .CompilerFamily when needed.

Note: the .bff files in the FASTBuild source repository configure how FASTBuild builds itself (which uses MSVC on Windows). They do not constrain which compiler is used to build other projects - for that, point a Compiler() at the toolchain to use, as shown below.

FASTBuild does not read the CC/CXX environment variables to select a compiler; declare a Compiler() explicitly (and #import CXX if environment-driven selection is desired).

Code (main.cpp)
#include <cstdio> int main() { std::printf( "Hello!\n" ); return 0; }
Configuration (fbuild.bff) - MSVC

The paths below are illustrative - adjust .VSBasePath, .WindowsSDKBasePath and .WindowsSDKVersion to match your installed Visual Studio and Windows SDK.

// HelloWorld - MSVC //------------------------------------------------------------------------------ // Windows Platform (MSVC compiler + Windows SDK) //------------------------------------------------------------------------------ .VSBasePath = 'C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.44.35207' .WindowsSDKBasePath = 'C:\Program Files (x86)\Windows Kits\10' .WindowsSDKVersion = '10.0.26100.0' // Settings //------------------------------------------------------------------------------ Settings { .Environment = { "PATH=$VSBasePath$\bin\Hostx64\x64", "TMP=C:\Windows\Temp", "SystemRoot=C:\Windows" } } // Compiler //------------------------------------------------------------------------------ Compiler( 'Compiler-MSVC' ) { .Executable = '$VSBasePath$\bin\Hostx64\x64\cl.exe' } // ToolChain //------------------------------------------------------------------------------ .Compiler = 'Compiler-MSVC' .CompilerOptions = '"%1"' // Input + ' /Fo"%2"' // Output + ' /c' // Compile only + ' /Z7' // Debug format (in .obj) + ' /nologo' // No compiler spam + ' /W4' // Warning level 4 + ' /WX' // Warnings as errors + ' /I"./"' + ' /I"$VSBasePath$\include"' + ' /I"$WindowsSDKBasePath$\Include\$WindowsSDKVersion$\ucrt"' + ' /I"$WindowsSDKBasePath$\Include\$WindowsSDKVersion$\shared"' + ' /I"$WindowsSDKBasePath$\Include\$WindowsSDKVersion$\um"' .Linker = '$VSBasePath$\bin\Hostx64\x64\link.exe' .LinkerOptions = ' /OUT:"%2"' // Output + ' "%1"' // Input + ' /WX' // Warnings as errors + ' /NOLOGO' // No linker spam + ' /DEBUG' // Keep debug info when linking + ' /LIBPATH:"$VSBasePath$\lib\x64"' + ' /LIBPATH:"$WindowsSDKBasePath$\Lib\$WindowsSDKVersion$\ucrt\x64"' + ' /LIBPATH:"$WindowsSDKBasePath$\Lib\$WindowsSDKVersion$\um\x64"' // HelloWorld //------------------------------------------------------------------------------ ObjectList( 'HelloWorld-Obj' ) { .CompilerInputPath = '.\' .CompilerOutputPath = 'Out\' } Executable( 'HelloWorld' ) { .Libraries = { 'HelloWorld-Obj' } .LinkerOutput = 'Out\HelloWorld.exe' } // All //------------------------------------------------------------------------------ Alias( 'all' ) { .Targets = { 'HelloWorld' } }
Configuration (fbuild.bff) - MinGW-w64 (GCC / Clang)

MinGW-w64 ships its own headers, import libraries and runtime, so no Visual Studio or Windows Kits installation is required. Point .MinGWBasePath at the root of your MinGW-w64 install (the folder that contains bin\g++.exe). To build with Clang instead of GCC, replace g++.exe with clang++.exe.

// HelloWorld - MinGW-w64 (GCC / Clang) //------------------------------------------------------------------------------ // MinGW-w64 install root (contains bin\g++.exe) //------------------------------------------------------------------------------ .MinGWBasePath = 'C:\mingw64' // Settings //------------------------------------------------------------------------------ Settings { // The MinGW bin dir must be on PATH so the compiler and the DLLs it depends // on can be found. SystemRoot and TMP are needed by spawned processes. .Environment = { "PATH=$MinGWBasePath$\bin", "TMP=C:\Windows\Temp", "SystemRoot=C:\Windows" } } // Compiler //------------------------------------------------------------------------------ Compiler( 'Compiler-MinGW' ) { .Executable = '$MinGWBasePath$\bin\g++.exe' // or clang++.exe // .CompilerFamily is auto-detected from the executable name (here: gcc). // Only set it for a non-standard/wrapper exe name FASTBuild can't detect; // the value is the family, e.g: .CompilerFamily = 'gcc' } // ToolChain //------------------------------------------------------------------------------ .Compiler = 'Compiler-MinGW' .CompilerOptions = '"%1"' // Input + ' -o "%2"' // Output + ' -c' // Compile only + ' -g' // Debug info + ' -Wall' // Enable warnings + ' -Werror' // Warnings as errors + ' -I./' // g++ / clang++ act as the linker driver here. FASTBuild only auto-detects a // GCC-style linker from an executable named 'gcc'/'gcc.exe', so set .LinkerType // explicitly. clang++ is also driven as 'gcc' (there is no separate 'clang' type). .Linker = '$MinGWBasePath$\bin\g++.exe' // or clang++.exe .LinkerType = 'gcc' .LinkerOptions = ' -o "%2"' // Output + ' "%1"' // Input // (MinGW links the standard libraries automatically) // HelloWorld //------------------------------------------------------------------------------ ObjectList( 'HelloWorld-Obj' ) { .CompilerInputPath = '.\' .CompilerOutputPath = 'Out\' } Executable( 'HelloWorld' ) { .Libraries = { 'HelloWorld-Obj' } .LinkerOutput = 'Out\HelloWorld.exe' } // All //------------------------------------------------------------------------------ Alias( 'all' ) { .Targets = { 'HelloWorld' } }
